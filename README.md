# Habit Tracker

Личный трекер: привычки со счётчиком дней + календарь с цветными отметками и заметками.
React + TypeScript + Vite + Tailwind. Без базы — всё в `localStorage`, бэкап в JSON.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Страницы

**Привычки** (`#/`)
- Добавить привычку с датой старта (можно задним числом).
- Счётчик дней растёт сам от даты старта.
- «Обнулить» — серия начинается с сегодня, лучшая серия сохраняется.
- Клик по названию — переименовать.

**Календарь** (`#/calendar`)
- Клик по дню → справа панель: цветные отметки (Зал, Английский, свои) и заметка о дне.
- Заметка сохраняется автоматически; на дне с заметкой виден значок ✎.
- Статистика: сколько раз за месяц и за год по каждой категории.
- Категории: добавить, переименовать, поменять цвет, удалить.

## Данные

Ключ в localStorage: `habit-tracker:v1`. Данные живут в одном браузере, поэтому:
- **Экспорт JSON** — скачать бэкап.
- **Импорт** — загрузить бэкап (заменяет текущие данные).

Формат:

```json
{
  "version": 1,
  "habits": [{ "id": "…", "name": "Без сахара", "startDate": "2026-10-01", "createdAt": "2026-10-01", "bestStreak": 12 }],
  "categories": [{ "id": "…", "name": "Зал", "color": "#22c55e" }],
  "days": { "2026-10-23": { "marks": ["<id категории>"], "note": "Грудь + спина" } }
}
```

## Деплой (по желанию)

`base: './'` в `vite.config.ts`, так что `dist/` можно выложить на GitHub Pages
или любой статический хостинг. Учти: на приватной репе Pages доступен только на платных планах.
